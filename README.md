# Shubham Ghodekar — Portfolio

Personal portfolio website. Single-page, zero dependencies, no build step — plain HTML, CSS, and JavaScript.

**Live:** [shubham302004.github.io](https://shubham302004.github.io)

## Structure

```
├── index.html      # All content
├── style.css       # Styles, dark mode, responsive
├── script.js       # Menu, theme toggle, scroll animations
└── assets/
    ├── shubham.png
    └── Shubham_Ghodekar_Resume.pdf
```

## Features

- Light / dark theme with system-free toggle
- Mobile-first responsive layout with hamburger nav
- Scroll-reveal animations and animated stats (IntersectionObserver)
- Targeted at AI Engineer, ML Engineer, and Data Analyst roles

## Run locally

Open `index.html` in a browser — that's it. No dependencies to install.

## Deploy

Push to GitHub, then enable **Settings → Pages → Deploy from branch → main / root**.
